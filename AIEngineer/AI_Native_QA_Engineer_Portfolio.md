# Original Job Description

## About the Job

We are looking for an AI-Native QA Engineer who embraces automation,
leverages AI tools daily, and is excited to explore the future of
agentic testing and intelligent quality assurance.

This is not a role for someone who occasionally uses AI assistants. We
are seeking a QA professional who actively integrates AI tools into
their engineering workflow to improve productivity, coverage, and
software quality.

## Key Responsibilities

-   Build, maintain, and scale automated test frameworks using
    Playwright or Selenium.
-   Develop automated test coverage for web applications, APIs, and
    end-to-end user journeys.
-   Leverage AI tools such as OpenAI, Claude, Gemini, or similar
    platforms to accelerate test case creation, defect analysis, and
    coverage planning.
-   Explore and implement AI-assisted and agentic QA workflows to
    improve testing efficiency and effectiveness.
-   Integrate automated test suites into CI/CD pipelines using GitHub
    Actions, Jenkins, or similar tools.
-   Perform API testing, backend validation, and SQL-based data
    verification.
-   Collaborate closely with Product, Design, and Engineering teams to
    ensure quality throughout the software development lifecycle.
-   Investigate defects, identify root causes, and validate fixes.
-   Continuously improve automation coverage, testing processes, and
    quality engineering practices.

## Must Have

-   2--4 years of QA experience in a Product or SaaS environment.
-   Hands-on experience building automation frameworks from scratch
    using Playwright or Selenium.
-   Demonstrated use of OpenAI, Claude, Gemini, or similar AI tools in
    an engineering or QA workflow.
-   Strong understanding of AI agents, prompt engineering, tools, and
    AI-driven workflows.
-   Ability to write and troubleshoot automation scripts using Python,
    JavaScript, or Node.js.
-   Comfortable reading application code, debugging issues, and
    collaborating with developers on technical solutions.
-   Experience in API testing and automation.
-   Good understanding of SQL and database validation.
-   Experience integrating automated tests into CI/CD pipelines.
-   Strong analytical, debugging, and problem-solving skills.
-   BE/BTech or ME/MTech degree.

## Good to Have

-   Experience with BDD frameworks such as Gherkin or Cucumber.
-   Familiarity with Jira, Zephyr, or similar test management tools.
-   Exposure to MCP (Model Context Protocol) or similar agent
    frameworks.
-   API automation using Postman, REST Assured, or Playwright.
-   Experience working in Agile/Scrum product teams.
-   Knowledge of performance, security, or accessibility testing.
-   Ability to investigate failures beyond the test layer by analyzing
    application code and identifying likely root causes.
-   Experience reviewing development codebases to pinpoint areas
    requiring fixes and collaborating with engineers on implementation
    approaches.
-   Hands-on experience contributing bug fixes, testability
    improvements, or small code changes directly to the application
    codebase.
